# Once Upon a Time Photography

A modern, minimalist photography portfolio built with Next.js (App Router) and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Design System

- **Background:** `#F5F0E6` (soft warm beige)
- **Text:** `#4A4238` (deep espresso brown)
- **Heading font:** Playfair Display
- **Body font:** Inter
